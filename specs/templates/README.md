# Working templates

Use these templates only when the work warrants a persistent record. Small compliant fixes may use the [pull-request template](../../.github/pull_request_template.md) rather than create a separate task file.

[Task and handoff](task.md) records implementation scope and continuation context. [Decision](decision.md) records proposed architectural changes. [Module](module.md) supplies the common specification structure. [Evidence](evidence.md) records actual verification.

Replace placeholders before treating a copied template as a real record. Register new normative specifications and decisions in [the catalogue](../catalog.json). Task records and evidence reports are not independent authorities; do not turn them into a second evolving product plan. Put long-lived tasks in the repository's existing task system where available and link them from the pull request.
