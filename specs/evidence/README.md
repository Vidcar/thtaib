# Verification evidence

No `verified` product reports are included. Application unit checks exist and are registered in [commands](../commands.md); they are not catalogue `verified` evidence and do not replace David-PC UAT. The supplied checker tests verify the governance tooling only.

Add concise, sanitised reports here using [the evidence template](../templates/evidence.md). Follow [verification](../verification.md) and link passing reports from the corresponding catalogue entries. Historical reports may remain for traceability, but only evidence valid for the current scoped claim belongs in an active `verified` entry.

Do not commit secrets, personal documents, model weights, large binary project snapshots or unredacted model context. Store necessary external artifacts in an approved location and record provenance/integrity and access limits in the report. An inaccessible log is not evidence a future reviewer has actually inspected.
