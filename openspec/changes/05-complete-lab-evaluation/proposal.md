# Complete exclusive Lab evaluation and configuration comparison

## Why

Lab must turn actual model and task executions into reusable, interpretable evidence without a second agent engine or disruptive uncoordinated benchmarks.

## What Changes

Complete exclusive Lab ownership, case capture/restore, real Inspect evaluation, deterministic outcome checks, structured llama-bench measurements, comparison history and deliberate reuse of tested settings.

The proposed LAB-005 replacement deliberately retires the historical one-issue-per-trait rule in favour of this OpenSpec change's bounded delivery. The LAB-006 replacement permits explicit tested-configuration reuse while retaining separate trait and task-case flows. These are proposed changes to the current contract, not claims about current implementation.

## Capabilities

### Modified Capabilities

- `lab-evaluation`: Extend the existing separate Model Lab and task-case flows, replacing the older prohibition on deliberate tested-configuration reuse.

## Impact

Work order **05 of 08**. Change 04 must be implemented and verified first. Reuse existing services and current contracts; an existing passing implementation satisfies a task without being rebuilt. The deltas specify the required end state, not a claim that every listed behaviour is absent.

## Non-goals

No second evaluation agent loop, automatic model judge, hidden auto-approval, unrelated downloads, automatic profile overwrite or requirement to complete later concurrency/media work in this change.
