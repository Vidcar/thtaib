# Complete exclusive Lab evaluation and configuration comparison

## Why

Lab must turn actual model and task executions into reusable, interpretable evidence without a second agent engine or disruptive uncoordinated benchmarks.

## What Changes

Complete exclusive Lab ownership, case capture/restore, real Inspect evaluation, deterministic outcome checks, structured llama-bench measurements, comparison history and deliberate reuse of tested settings.

The proposed LAB-005 replacement deliberately retires the historical one-issue-per-trait rule in favour of this OpenSpec change's bounded delivery. The LAB-006 replacement permits explicit tested-configuration reuse while retaining separate trait and task-case flows. These are proposed changes to the current contract, not claims about current implementation.

## Capabilities

### Modified Capabilities

- `lab-evaluation`: Extend the existing separate Model Lab and task-case flows, replacing the older prohibition on deliberate tested-configuration reuse.

## Impact

Work order **05 of 08**. Changes 04 and `migrate-local-agent-interaction` must be implemented and verified first. Consume the shared SDK run-observation boundary for live presentation, while retaining Lab-owned Inspect evaluations, case/scorer versions, measurements, durable evidence links and result history. SDK hooks or projections do not perform evaluation or establish task correctness. Reuse existing services and current contracts; an existing passing implementation satisfies a task without being rebuilt. The deltas specify the required end state, not a claim that every listed behaviour is absent.

Lab must present a coherent user journey: choose a case, choose configurations, run, compare results, inspect evidence, then deliberately use the tested setup in Chat. Trait testing remains separate from task cases. The UI must make Lab's exclusive-use state visible wherever it blocks other work, and it must not require interpreting raw JSON, internal IDs or backend terminology to complete the primary journey. Detailed Lab layout is deliberately deferred to this packet's pre-implementation checkpoint.

## Non-goals

No second evaluation agent loop, automatic model judge, hidden auto-approval, unrelated downloads, automatic profile overwrite or requirement to complete later concurrency/media work in this change.
