# Proposal

## Why

The compact Workbench delivery established the intended ownership and Chat direction, but several saved-record editors retained older presentation and control regressions. Dave approved a complete visual polish pass grounded in the discovery decisions, with specific applied values replacing generic "Inherited" labels; generated images and HTML are guides.

## What Changes

- Unify responsive catalogue/detail editing for Models, Agents and Knowledge, semantic icons, short copy, disclosure summaries and truthful empty/loading/error states; retain local unsaved drafts during navigation.
- Show effective values first, default sources second, and specific reset targets without pinning displayed defaults or changing internal inheritance semantics.
- Repair Models preview ownership, dirty state, saved/load labels, configuration/card/files hierarchy, context sliders and advisory hardware presentation/refresh; retain exact import files, provenance, capabilities and nonblocking estimates.
- Complete guided agent Review and grouped tools/knowledge/helper editing; missing helpers remain removable. Keep Knowledge creation in the editor, native source/resources lossless, operational settings compact and independent, and partial capture updates nondestructive.
- Give Files/Browser/Helpers one persistent dock geometry and per-conversation view state; retain uploads/reused copies after responses, provenance, and correct browser/permission/picker/tuning/readiness states.
- Remove global Library Use in Chat and add working project/chat filters, recognizable origins and useful previews; preserve Chat reuse and backend retained-file authority.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `backend-desktop`: clear value/default controls, responsive saved-record workspaces, shared dock geometry/state and Library actions.
- `models`: catalogue/detail presentation and accurate model/configuration previews, reset targets and advisory import controls.
- `agents-workflows`: partial capture configuration updates preserve omitted settings.

## Impact

Use the existing React desktop and backend resolver, model/import, saved-agent, knowledge and retained-file owners. No new public endpoint, runtime, storage authority or dependencies are planned. Preserve model weights, product records, exact saved/accepted setup semantics, revision checks and safe reload. Workflows/Lab feature development remains separate. Validate actual Windows use plus relevant deterministic regressions and established local gates; own Git and local delivery.
