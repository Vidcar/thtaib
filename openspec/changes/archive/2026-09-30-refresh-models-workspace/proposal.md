# Proposal

## Why

Models currently spreads routine setup and installation across large panels and extra stages. The agreed mock makes choosing, saving and loading models easier while retaining the real native controls and truthful lifecycle evidence.

## What Changes

- Replace Models with compact My models and Add models tabs, Generation/Loading columns, header check icons, inline help/reset and collapsed specialist settings.
- Keep each supported native control once, including exact GPU layers. Put Create/Delete beside the setup selector and rename/copy/preferred/revert in a small menu.
- **BREAKING**: Allow zero named setups. Imports create only selected usable card recipes; without recipes, require a named manual save before Load. Remove implicit Default/Import settings and last/default deletion restrictions without compatibility shims.
- **BREAKING**: Replace Review and Downloads pages with Find → Choose and explicit Download/Add, durable inline progress, Cancel/Retry and contextual job details. Move installation storage controls to Settings.
- Add friendly bundle renaming across current model consumers without changing stable identity, files or compatibility.
- Persist automatic checks after healthy loads, reuse matching behavioral evidence across reloads and expose individual icon retests. Audio/video checks remain deferred.
- Use total-capacity advisory discovery estimates, exact variant tiles and bounded source metadata, preserving available-memory admission and Chat semantics.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `models`: setup lifecycle, compact controls, installation flow, capacity preview, checks and model names.
- `backend-desktop`: compact Models exceptions to standing settings prose and explicit zero-setup selection.

## Impact

Backend model manager/configuration/import/capability/metadata owners, application persistence, generated API contracts and desktop Models/shared model selectors. Chat, Agents, projects and Lab must display new names and surface missing setup references. Scoped CSS must preserve shared controls and the delivered 54px rail/resource rings. No new inference engine, harness, external dependency or weight migration.
