# Simplify Models and configure Deep Agents directly

## Why

Models has accumulated competing controls, repeated default/status text and hidden output reservations that make common settings difficult to use and trigger premature compaction. Restore a compact, truthful editor and configure upstream inference/context mechanisms directly.

## What Changes

- Show common generation, sampling and loading controls in two compact responsive columns, with one Model card preset entry point and contextual details.
- Initialise model settings from compatible publisher recommendations and native/template defaults; display resolved values rather than redundant Default choices.
- Use one 1,024-token Context slider, fast metadata-based memory preview and an optional native allocation check.
- **BREAKING** Remove Workbench automatic output allowance policies/bindings and its 8% context deduction. Default native output is Unlimited and Deep Agents receives full observed per-request capacity.
- Replace the budgeting summarizer with configured stock Deep Agents middleware, native local token counting and upstream overflow recovery.
- Audit setting mappings and remove unsupported application restrictions; reset Dave's disposable model settings while retaining weights and unrelated state.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `models`: compact controls, publisher/native baseline, unrestricted default output, truthful context accounting and metadata-first memory preview.
- `agents-workflows`: stock configured Deep Agents context management without application budget overrides.

## Impact

Backend inference configuration, adapter, embedded harness, memory calculation and shared wire schemas; desktop Models/import/Chat controls; affected local/native tests. Existing pinned dependencies and managed inference lifecycle remain authoritative. No new service, runtime, or storage authority.
